## 3. 核心状态 `S`

```
M 天体总质量（决定阶段/引力/结算，不会减少）   B 可用质量（买东西花掉）
prod{pXY:数量}  stage 0~6  ignited  T 核心温度  E 能量  fe 铁进度 0~1  burn 燃烧速度 0.5~3
sats 卫星数  sacrificed 献祭数  lv{升级id:等级}  runTime  seen{里程碑}  route 选定路线
eventT 下次捕获倒计时  capture{t,mass}  stormT stormCD  flareT  collapsed
meta{h,G,dm}  cc 宇宙常数  runs 第几个宇宙  found[] 见过的终局（跨宇宙保留）
```

## 4. 阶段与数值

| s | 名称 | 门槛 thr (kg) | 点击动词 | 半径 r | DRAG |
| --- | --- | --- | --- | --- | --- |
| 0 | 虚空 | 0 | 聚集 | 2–4 | 1 |
| 1 | 尘埃云 | 1e10 | 聚集 | 14–30 | 1 |
| 2 | 小行星 | 1e18 | 撞击 | 8–20 | 0.7 |
| 3 | 岩质行星 | 1e24 | 撞击 | 16–30 | 0.3 |
| 4 | 气态巨行星 | 1e27 | 卷入 | 28–42 | 0.22 |
| 5 | 褐矮星 | 1e29 | 压缩 | 30–34 | 0.16 |
| 6 | 恒星 | 2e30（且 T≥3e6 K 点燃） | 吸积 | 26–44 | 0.015 |

- 阶段进度是**对数刻度**：`(log10 M − log10 thr_s) / (log10 thr_{s+1} − log10 thr_s)`；恒星阶段用 `fe`。
- 天体半径 = `r[0] + (r[1]−r[0]) × 进度`。
- 元素：fe ≥ 0.15 He / 0.35 C / 0.6 O / 0.8 Si，每个 +10% 吸积。
- 里程碑：1e3 小汽车、1.5e5 蓝鲸、6e9 金字塔、2.2e14 哈雷彗星、9.4e20 谷神星、7.35e22 月球、5.97e24 地球、1.9e27 木星、1.99e30 太阳。

### derive()（全部公式）

```
base = 0.012·well + (st≥1 ? 0.004 : 0) + 0.004·static + 0.005·orbit + sats·(0.002 + 0.001·tidal)
mult = (sats≥3 ? (reson?2:1.5) : 1) · 1.2^atmo · (reson?1.5:1.3)^sacrificed · 1.25^lens · 1.3^disk · (1+0.25·G)
       ×3 风暴中；×5 耀斑中；恒星阶段再 × burn · 1.15^convect · (1+0.1·元素数)
k    = base·mult·DRAG[st]；恒星阶段 k = 0（v0.1.3：以前封顶 0.005，会指数失控）
flat = Σ吸积源产出 × mult
rate = M·k + flat
click = 3^click·2^h + M·0.001·1.2^click·2^h·DRAG + rate·shard
critP = st≥2 且 crit≥1 ? 0.05+0.05·crit : 0（v0.1.3：大陨石必须在进化树解锁，1 级 10%，之后每级 +5%；以前小行星阶段白送 10%）；critX = 10+5·comet
Erate = st≥6 ? (M/1e30)·1e26·1.5^fusion·burn : 0
slots = 1+slot
heat  = 4e3·(M/1e29)^0.7·1.5^contract + sats·8e3·theat
decay = 0.03·0.7^core；clickHeat = 2e4·2^shock
```

### tick(dt)

1. `M += rate·dt`（B 同步加）。补算中：质量封顶在当前阶段进度 95%（不低于补算开始时的 M）。
2. 阶段推进到 5 为止（M ≥ 下一门槛）。
3. 褐矮星：`T += (heat − decay·T)·dt`；T≥3e6 且 M≥2e30 且不在补算 → 点燃进恒星。
4. 恒星：`E += Erate·dt`；`fe += burn^1.6/1200·dt`；补算中 fe 封顶 0.95；fe≥1 → 坍缩。
5. 捕获（stage≥3，或 stage2 且买了捕网）：间隔 `(22+rand·10)·0.8^net` 秒，持续 12 秒，质量 `rate·35 + 0.02·M`。可吞并或留作卫星（有空槽时）；3 颗成星环。
6. 风暴（stage≥4）：每 40 秒判定一次，概率 `0.35+0.15·density`，持续 `25+5·density` 秒。
7. 里程碑提示。

### 升级（UPGS：id 列 阶段 c0 g max，价格 c0·g^lv）

- **主干**：click 0/15/5/12 · well 0/40/8/8 · static 1/3e10/25/10 · atmo 4/2e27/8/10 · density 4/5e27/20/3 · core 5/2e29/6/5 · fusion 6/5e28/3/10（能量）· convect 6/1e29/4/10（能量）
- **撞击之路 → 中子星**：crit 2/4e18/30/6 · shard 3/2e24/20/5 · comet 4/4e27/30/2 · shock 5/2e29/8/3 · nstar 6/4e28/1/1（能量，终局 ×1.3）
- **引力之路 → 黑洞**：orbit 2/2e18/40/8 · lens 3/5e24/25/4 · disk 4/5e27/30/3 · contract 5/3e29/6/6 · bhole 6/8e28/1/1（终局 ×1.5）
- **轨道之路 → 白矮星**：net 2/3e18/30/3 · slot 3/3e24/20/4 · tidal 3/1e25/30/6 · reson 4/3e27/1/1 · theat 5/2e29/6/3 · wdwarf 6/3e28/1/1（终局 ×1.2，每颗卫星再 +1 CC）
- **路线锁定**：买第一个非主干节点即选定 `S.route`，本宇宙另两条锁定。终局在到达恒星阶段（或以前见过 `found`）之前显示「？？？」。

### 吸积源（PRODS）

- 每阶段一组（恒星阶段没有），id `p{阶段}{序号}`。价格 `c0 = 10^(lo + (hi−lo)·f)`，lo/hi 是本阶段与下阶段门槛的 log10；`p00` 固定 15 kg。
- 产出 `c0 / PB[j]`，PB = [20, 40, 75, 120]；每买一个贵 15%。批量 ×1 / ×10 / 最大。
- 没见过的显示「？？？」：买过上一个、或买得起一半价格时揭晓。
- 之前阶段的吸积源继续工作，吃当前倍率。

### 坍缩与重生

- `endMult` = 黑洞 1.5 / 中子星 1.3 / 白矮星 1.2 / 无 1
- `CC = max(1, floor(1.2·log10(max(Mig,1e29)/1e29)·(1+0.1·元素数)·endMult) + (白矮星 ? sats : 0))`，Mig = 点燃那一刻的质量 `S.Mig`（v0.1.3；以前用坍缩时质量，朋友第一轮拿了 100+ CC）。模拟：每轮 7~11 CC。
- 重生保留 meta、cc、runs+1、found。元升级：h（点击 ×2，c0 1）、G（吸积 +25%，c0 1）、dm（v0.1.3：开局质量 `min(1e9, 10^(2+2·dm))`，最多 4 级，不再跳阶段；以前 `10^(4+4·dm)`，c0 2），价格 `ceil(c0·1.6^lv)`。

### 其他机制

- **耀斑**：花 `Erate·25` 能量，10 秒吸积 ×5。
- **献祭卫星**（stage≥4）：卫星 −1，永久吸积 ×1.3（共振 ×1.5）。
- **离线补算**（标签页切走后回来，elapsed>1 秒）：5% 效率、最多计 4 小时、最多 4000 步；不进下一阶段（停在 95%）、不点燃、fe 不超过 95%；期间不弹提示不放音效，结束后一条汇总提示。
- **测试加速**按钮：×10。清空存档需 3 秒内点两次。

## 5. 像素渲染要点

- 192×192 缓冲，`put(x,y,r,g,b,a)` 做 alpha 混合，最后 `putImageData`，CSS `image-rendering: pixelated` 放大。
- 天体：虚空=发光点+飘尘；尘埃云=旋转尘粒+核心；小行星=噪声边缘不规则岩块；岩质=球面 fbm（海、陆、冰盖随进度变化）；气态=条纹+大红斑（风暴时亮斑）；褐矮星=暗红球+热辉光；恒星=按 burn 变色（橙→白→蓝）+闪烁日冕。
- 球面光照量化成 5 档（像素风）；循环边界用 `ceil(r)` 取整（以前小数边界漏像素出黑点）。
- 卫星：stage 2~5 且 sats>0 时绕行（v0.1.2 修复：以前 stage 2 不画）；星环：stage 3~4 且 sats≥3。
- 阶段切换动画 `trans`：旧天体缩小 → 闪白 → 新天体长大（1.3 秒）。
- **点击飘字**（v0.1.3）：`popText(gain, crit, pos)` 在 `#pops` 里生成 DOM，CSS 动画上飘淡出；画布点击用指针位置，按钮/空格在天体附近随机。最多 30 个。
- **大陨石表现**（v0.1.3）：暴击时 `meteors.push`，`drawMeteors()` 画 0.32 秒飞行（带尾巴）→ 落地时闪光 0.3、震屏 `shake`（CSS transform）、碎石外溅（粒子带 vx/vy）、冲击波 `shocks`、播放 crit 音效。

## 6. 已知问题与待定设计

- **节奏**：模拟显示小行星阶段只有约 1~2 分钟（每秒 7% 左右的引力吸积，10 秒翻倍），且点击几乎不影响速度。用户想把它做成约 20 分钟、以点击为主的重要阶段。
- **已定设计（还没写代码、没写进策划案）：小行星之后分化演化**
  - 只有一个点击按钮，点击单纯加质量，**不计权重**。
  - 小行星阶段进化树节点用三种颜色标识，**不明示**撞击 / 引力 / 轨道之路；三种颜色可以混着买，不再买第一个就锁路线。
  - 权重 = 花在每种颜色节点上的质量（越贵分量越重）。
  - 带暗示：天体外观随权重占比慢慢变化（偏撞击更粗糙、偏引力裹一层气、偏轨道泛冰光）。
  - 小行星阶段质量到顶时揭晓「走向 X 之路」，并分化：撞击 → 岩质行星、引力 → 气态巨行星、轨道 → 液态（海洋）行星；此后锁定路线。
  - 权重打平：在打平的路线之间按权重随机选。
  - 小行星阶段目标时长约 20 分钟（现在只有 1~2 分钟，需要重调吸积/门槛）。
  - 分化后三条线目前**都能长到恒星**。
  - 点燃改为手动：满足条件时场景里出现「开始核聚变」按钮，玩家点下后播放点燃演出，变成恒星（不再自动点燃）。
  - 点燃时质量不足 → 褐矮星结局（短暂发亮后熄灭，提示质量不足、核聚变未能持续），直接进入下一个循环；质量够 → 恒星。
  - **结局由恒星最终质量决定（不再跟路线绑定）**：小 → 白矮星，中 → 中子星，大 → 黑洞（现实约 8 / 20 倍太阳质量为界）。路线和结局可自由组合，如「液态行星出身的黑洞」。原来的 nstar / bhole / wdwarf 终局节点需要重做。
  - 未定：三条线分化后到恒星之间的中间阶段；点燃条件是否三条线不同；质量分界线的具体数值（现在点燃时质量约 2e32 kg≈100 倍太阳质量，需要整体重标）。
- 引力路线偏强（平衡问题）。
- 策划案「待定决策」里还有：恒星类型代替燃烧速度、主线物理准确性、洛希极限撕碎卫星形成星环、更多正反馈。
